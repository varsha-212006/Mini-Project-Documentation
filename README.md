## 📖 Project Overview

The **Student Management System** is a software application used to manage student records. It allows users to add, update, delete, and search student information efficiently.

---

## 🎯 Objectives

- Maintain student records.
- Reduce manual paperwork.
- Provide quick access to student information.
- Improve data management.

---

## ✨ Features

- 👨‍🎓 Add Student
- ✏️ Update Student Details
- ❌ Delete Student
- 🔍 Search Student
- 📋 View Student List
